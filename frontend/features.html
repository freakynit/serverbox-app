Features

Everything you reach for over SSH, in one window.

Serverbox brings the everyday Linux operations you already run by hand into one calm window — with browser-style workspace tabs so you can keep several servers, or several views of one server, open side by side and drag to reorder.

Core

The essentials

The essentials that make a control panel worth opening instead of a terminal. Everything else builds on this layer.

SSH connection management

Multiple profiles with password or private-key auth, key discovery & ssh_config import, connection testing, automatic reconnect, bastion routing, tags/groups/search, and secrets in an encrypted local vault.

Server dashboard

Hostname, OS, kernel, arch, uptime, load, CPU utilisation, core count, RAM, swap, per-mount disk and network interfaces — connecting first, then filling cards progressively.

Integrated SSH terminal

Real PTY, interactive commands, resize, ANSI/xterm, copy/paste, history, reconnect, sudo, and shell detection via xterm — sessions are bound per workspace tab so you can keep a shell alive while switching tabs.

Process manager

PID, process/user, CPU & RAM %, RSS, command and runtime, with sort/filter/search, periodic refresh, SIGTERM and SIGKILL.

systemd service manager

List with running/stopped/failed state and search; start, stop, restart, reload, enable and disable; unit details and recent journal entries.

Remote file manager

SFTP browser with breadcrumbs, upload/download, rename, delete, create, permissions, ownership, hidden files, text preview & editor, and drag-and-drop uploads.

Directory transfers

Recursive directory upload/download preserving hierarchy and permissions where possible, with progress, cancel/retry and conflict handling.

Docker & Podman

Containers, stats, logs, exec shells, port mappings, mounts, networks; images, volumes, networks with inspect, pull and GUI creation.

Logs

Journalctl viewer by service, follow/tail, pause, search, severity, time range and copy/export — plus Docker container log sources.

Ports & connections

Listening ports and established connections, TCP/UDP, local & remote addresses, PID and process name, IPv4/IPv6, with PID-to-service mapping.

Light & dark appearance

A calm, cross-platform desktop workspace with a full light/dark visual system and responsive layout.

Workspace tabs

Browser-style, drag-reorderable tabs for parallel connections. Open the same server twice for side-by-side compare — each tab keeps its own view, dashboard snapshot and terminal sessions.

Multiple servers

A sidebar of machines with groups, tags, favorites, search, status indicators, recent ordering and fast switching across every saved profile — plus workspace tabs so many can stay open at once.

Workspace tabs

Stay in several places at once.

A browser-style tab strip above the workspace lets you keep many server workspaces open in parallel. Tabs are draggable, remember their order, and each one keeps its own view, overview snapshot, and terminal sessions — even when two tabs point at the same host.

  • Parallel connections — mix different servers or the same server opened twice for comparison.
  • Each tab remembers its view, snapshot metrics and bound terminal sessions.
  • Drag tabs to reorder with a live drop indicator; close any tab without disconnecting siblings.
  • Switching tabs is instant — no re-fetch until you hit Refresh.

Bastion & jump hosts

Reach locked-down servers through a bastion.

Pick any saved profile as the jump host for another, and Serverbox chains the connection hop by hop — recursive ProxyJump-style routing for terminals, SFTP, commands, and tunnels alike.

  • Each hop authenticates with its own encrypted credentials and verified host key.
  • Routes can be nested several layers deep; cycles are caught before you connect.
  • Deleting a bastion cleanly unlinks its dependent connection profiles.

Administration

Everyday upkeep

Tools that quietly hide themselves when a server can't support them, instead of failing late.

Cron manager

Current-user crontab add/edit/delete, enable/disable, validation, presets, human-readable schedules and next-run estimates; read-only /etc/crontab & /etc/cron.d.

APT packages

Installed & available package search, package details, pending upgrades, update, install, remove and upgrade on Debian & Ubuntu.

Users & groups

UID/GID, home, shell, membership, last login & lock state; create/delete users, lock, change shell/group, and warned password resets.

Workspace tabs

Browser-style, drag-reorderable tabs for parallel connections — open the same server in two tabs, each with its own view, snapshot and terminals, and reorder by dragging.

Multi-server UX

Grouped & tagged sidebar, favorites, recent ordering, status indicators, fast switching and profile duplication.

Sudo & root access

Use root, passwordless sudo, or your encrypted per-server sudo credential — resolved safely, and never exposed on the command line.

Reliable remote commands

Every action runs over SSH with cancellation, reconnect on a dropped connection, and clean output — so long-running commands survive a flaky link.

Smart feature gating

On connect, Serverbox detects what each server supports — distro, package manager, init system, containers and sudo — and only shows the tools that actually work there.

Master password

Setup, change and complete credential reset with explicit unrecoverable-password warnings. Host keys verified through known_hosts with fingerprint review.

Fast on big servers

Large remote collections load in pages instead of one big snapshot, and the overview stops loading the moment you navigate away. Processes, services, entries and containers stream in as they arrive.

Operations

Operations

Where Serverbox pulls ahead of a plain SSH client — Compose, firewall, access management, security checks, and tunnels.

Docker Compose

Discover projects across the plugin, docker-compose & podman-compose; services, dependency topology, lifecycle, logs, exec, rebuild, pull and scale.

Firewall

UFW & firewalld rule visibility with guarded allow, deny, enable and disable. Explicit confirmation; no hidden fallback; the active SSH port stays allowed.

Authorized keys

Remote authorized_keys management with fingerprints, add/remove, and lockout warnings before you replace a key that could lock you out.

Security posture

Update & reboot status, kernel and container-runtime version checks, and common one-click maintenance actions across the host.

Saved commands

A dedicated workspace for named actions like "Tail API logs" or "Check Docker disk usage" — edit, delete, and run on demand.

SSH tunnels

Local, remote and SOCKS5 forwarding saved as first-class workspaces, run on independent verified SSH sessions — never persisted.

Server notes

Purpose, provider, production/staging, URLs and emergency instructions — stored with the profile and included in sidebar search.

Compose topology

A dependency graph per Compose project. Environment variable names are shown; resolved values are never rendered.

One-click actions

Reboot, restart SSH, restart Docker, update package indexes and install common tooling — guarded server actions you can confirm and run.

Fast Compose scanning

Finds Compose projects under your home directory and common locations in a single SSH pass, so even busy servers stay responsive.
