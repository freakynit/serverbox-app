Core

The everyday operations, in one window.

The essentials you reach for every time you SSH in — gathered into one calm window instead of a dozen terminals.

SSH connections & vault

Multiple profiles with password or private-key auth, ~/.ssh discovery, ssh_config import, host-key verification, and an encrypted local vault for every secret.

Server overview

CPU, memory, swap, disks, network interfaces, uptime and load — connecting first, then filling its cards progressively and cancelling the moment you leave.

Real PTY terminal

xterm-compatible sessions with tabs, resizing, copy/paste, sudo, SSH keepalives and reconnect — each stays bound to its workspace tab so you can keep a shell open while you check another server.

Processes

PID, user, CPU & RAM %, RSS, command and runtime with sort, filter, search, periodic refresh, and SIGTERM / SIGKILL.

systemd services

Start, stop, restart, reload, enable and disable — with search, unit details, and recent journal entries. Capability-gated where systemd is absent.

SFTP browser & editor

Navigate with breadcrumbs, edit text files remotely, and transfer files & whole directories with hidden files, permissions and ownership.

Docker & Podman

Containers, stats, logs, exec shells, images, volumes, networks, inspect, pull and creation — against whichever runtime lives on the endpoint.

Logs

Journalctl and container logs with the latest entries, time range, search, severity filters, live follow and copy. logread on minimal hosts.

Ports & connections

Listening ports and active connections via ss, falling back to BusyBox or netstat, with PID-to-service mapping.

Workspace tabs

Parallel work, without parallel windows.

Every server you open becomes a browser-style tab. Keep several workspaces side by side, duplicate a server into two independent views, and keep terminal sessions alive as you switch. Drag to reorder — the layout stays exactly how you left it.

  • Open many tabs at once — different servers, or multiple tabs for the same saved server.
  • Each tab keeps its own navigation, dashboard snapshot, and terminal sessions.
  • Drag tabs to reorder with a live insertion hint; close any tab without closing its server.
  • Switching tabs never re-fetches the overview — refresh only when you ask for it.

Bastion & jump hosts

Reach locked-down servers through a bastion.

Pick any saved profile as the jump host for another, and Serverbox chains the connection hop by hop — recursive ProxyJump-style routing for terminals, SFTP, commands, and tunnels alike.

  • Each hop authenticates with its own encrypted credentials and verified host key.
  • Routes can be nested several layers deep; cycles are caught before you connect.
  • Deleting a bastion cleanly unlinks its dependent connection profiles.

Beyond the basics

Where Serverbox pulls ahead of a plain SSH client.

Everyday administration tools, plus the operational depth most control panels skip — Compose, firewall, tunnels, and guarded maintenance actions.

Administration

Everyday upkeep tools that quietly hide themselves when a server can't support them, instead of failing late.

Cron manager

Current-user crontab add/edit/delete, presets, human-readable schedules and next-run estimates. System cron stays read-only.

APT packages

Installed & available package search, details, pending upgrades, update, install, remove and upgrade on Debian & Ubuntu.

Users & groups

UID/GID, home, shell, membership, last login & lock state, with creation, deletion, locking and warned password resets.

Workspace tabs

Browser-style, drag-reorderable tabs for parallel connections — open the same server twice, keep each view, snapshot and terminal session intact while you switch.

Multi-server sidebar

Grouping, tags, favorites, recent ordering, status indicators, fast switching and duplication.

Sudo & root access

Use root, passwordless sudo, or your encrypted per-server sudo credential — resolved safely, and never exposed on the command line.

Reliable connections

Reconnect on dropped sessions, SSH keepalives, and clean cancellation so long-running commands survive a flaky connection.

Operations

Compose, access, security, and forwarding tools for everyday server operations.

Docker Compose

Discover projects across Docker Compose and Podman Compose — services, dependency topology, lifecycle, logs, exec, rebuild, pull and scale.

Firewall

UFW & firewalld rule visibility with guarded allow, deny, enable and disable — explicit confirmation, no hidden fallback.

Authorized keys

Remote authorized_keys management with fingerprints and lockout warnings before you replace a key that could lock you out.

Security posture

Update & reboot status, kernel and container-runtime version checks, and common one-click maintenance actions.

Saved commands & tunnels

Dedicated workspaces for named commands and local, remote & SOCKS5 SSH tunnels.

Server notes

Purpose, provider, environment, URLs and emergency instructions — stored with the profile, included in sidebar search.

Compose topology

A dependency graph per project. Environment variable names are shown — resolved values are never exposed.
